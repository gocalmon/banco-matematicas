📐 Visor Interactivo de Aprendizaje

Bienvenido al Visor Interactivo

Para comenzar:

  1. Haz clic en 📁 Abrir para cargar cualquier archivo .json descargado desde Gemini.
  2. Usa 📚 Banco para buscar ejercicios publicados por curso, tema o dificultad.
  3. Si deseas generar un nuevo ejercicio, pulsa en 🤖 Prompt Gemini para copiar las instrucciones.
  4. Usa 🎓 Exportar Alumnos para generar una versión lista para enviar.
  5. Cuando tengas varios JSON aprobados, usa 🗂️ Catálogo para preparar el banco de GitHub Pages.

🗂️ Generador del catálogo para GitHub Pages

Todo se procesa localmente en tu navegador: los ejercicios no se envían a ningún servicio.

Selecciona la carpeta que contiene tus JSON. El generador incluirá únicamente ejercicios con esquema 4.0, metadatos completos, estado reviewed y huella de integridad válida. Los archivos pendientes, modificados, duplicados o defectuosos quedarán excluidos y se explicará el motivo.

Ejemplo: si los archivos se publicarán dentro de ejercicios/, conserva ese valor. Se respetarán las subcarpetas seleccionadas.
